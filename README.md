# Go Templates

Go language project template designed for gonew.

# Templates

* [fiber](fiber): Project initialization template based on Fiber framework
* [mcp](mcp): Project initialization template base on MCP SDK

# Usage

These templates were designed to work and be downloaded with [gonew](https://github.com/betterde/gonew).
